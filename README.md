# Great Dusk Forecast

A responsive, self-contained single-page website with a dark terminal-inspired interface.

## Features

- Responsive desktop and mobile layouts
- Animated status indicator and title effects
- Lightweight vanilla HTML, CSS, and JavaScript
- No external assets or runtime dependencies
- Ready for static hosting on GitHub Pages

## Local Preview

Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.
